# AI 卡片库 · 便携版

一个装在文件夹里就能用的 AI 卡片库：免安装、免联网、数据留在自己电脑上。把零散的知识点、提示词、灵感整理成一张张卡片，随手翻开就能用。

---

## 这是什么

「AI 卡片库」用来管理你日常积累的**卡片式内容**——一条提示词、一段结论、一个概念、一句想记住的话。每张卡片由三部分组成：

- **标题**：一句话说清这张卡片是什么
- **正文**：卡片内容本体
- **标签**：用来分组和检索，可以多个

「便携版」意味着它是一个**绿色免安装**的目录：拷到 U 盘、换台电脑、解压即用，不用装环境、不用注册账号、不依赖网络。数据以本地文件（或浏览器本地存储）形式保存，随时可以打包带走。

## 核心特性

- **零安装**：双击入口文件即可运行，不写注册表、不装依赖
- **本地优先**：卡片数据只存在本机，不上传、不联网
- **随身携带**：整个目录拷进 U 盘或网盘，换设备继续用
- **快速检索**：按关键词、标签、时间筛选定位卡片
- **导入导出**：整库导出为文件，方便备份、迁移和分享
- **轻量无负担**：纯前端实现，几十 MB 的空间占用

## 快速开始

### 方式一：直接打开（最简单）

1. 解压整个目录到任意位置（建议路径不含空格和中文特殊符号）
2. 双击入口文件（通常为 `index.html`）
3. 浏览器打开后即可新增第一张卡片

### 方式二：本地起一个静态服务（推荐，功能更完整）

某些浏览器对 `file://` 协议下的存储和读取有限制，起一个本地服务可以避免这些坑：

```bash
# 任选其一，在项目目录下执行
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080`。

### 方式三：U 盘随身携带

把整个目录复制到 U 盘根目录，在任意一台 Windows / macOS 电脑上双击入口文件即可使用。数据跟着目录走，拔出 U 盘即带走全部内容。

## 目录结构

```
AI卡片库-便携版/
├── index.html          # 入口页面
├── README.md           # 本文档
├── data/               # 卡片数据（备份时优先带走这个目录）
├── assets/             # 样式、图标、脚本等静态资源
└── docs/               # 使用说明、更新记录等文档
```

> 目录名可能与上表略有差异，以实际文件为准；`data/` 是最需要备份的部分。

## 数据与备份

卡片的全部价值在数据，不在程序。建议养成三个习惯：

1. **定期导出**：用「导出」功能把整库保存成文件，存到网盘或另一块硬盘
2. **带走 `data/`**：迁移或换电脑时，复制 `data/` 目录即可完整还原
3. **改前先备份**：升级版本、调整目录结构之前，先复制一份整个目录

如果你用的是浏览器本地存储模式，注意：**清理浏览器数据可能导致卡片丢失**，请务必先导出。

## 使用建议

- **一张卡片只讲一件事**：卡片越小，复用率越高
- **标签从少到多**：先定 5～8 个常用标签，避免标签泛滥后反而搜不到
- **标题写成句子**：`如何让模型输出稳定的 JSON` 比 `JSON` 更容易在列表里认出来
- **定期合并重复卡片**：同类内容攒够三张，就整理成一张更完整的卡片

## 便携版与安装版的区别

| | 便携版 | 安装版 |
| --- | --- | --- |
| 安装 | 解压即用 | 需安装程序 |
| 数据位置 | 程序目录内 | 系统用户目录 |
| 换电脑 | 拷目录即可 | 需重新安装并迁移数据 |
| 多设备同步 | 需手动拷贝/网盘 | 依赖账号体系 |

便携版换的是「省事」，付出的是「同步靠手动」。如果你需要在多台设备间实时同步，更适合搭配网盘目录使用。

## 常见问题

**打开是空白页？**
先确认入口文件路径正确、没有被压缩包套娃（解压后可能多一层同名目录）。若仍空白，用方式二起本地服务再试。

**卡片突然不见了？**
大概率是浏览器数据被清理，或换了浏览器/换了打开路径（本地存储按地址隔离）。先从备份文件导入还原，之后坚持定期导出。

**换电脑怎么迁移？**
复制整个目录过去即可。如果数据存在浏览器本地存储里，先在旧机器上导出，再到新机器导入。

**能在手机上用吗？**
把目录放到手机可访问的位置，用手机浏览器打开入口文件即可；小屏体验有限，主要建议在电脑上整理、手机上查阅。

## 自定义

- **改主题**：调整 `assets/` 下的样式文件中的颜色变量
- **改字段**：卡片字段（标题/正文/标签）的定义集中在数据处理部分，增删字段时记得同步调整导入导出逻辑，保持旧数据兼容
- **改默认标签**：在初始化配置里预置一套常用标签，新建卡片时直接勾选
